# AI Resume Analyzer

An interactive Resume Analysis Dashboard built using Streamlit, PyPDF2, and Pandas for analyzing PDF resumes, detecting technical skills, calculating ATS scores, and providing resume improvement suggestions.

The application helps users understand the strengths and weaknesses of their resumes by identifying detected skills, missing important skills, and generating basic recommendations.

---

## Features

* Upload resume in PDF format
* Extract resume text from PDF files
* Detect technical skills from resumes
* Calculate ATS score based on detected skills
* Identify missing important skills
* Generate resume improvement suggestions
* Add custom skills to the skills database
* View available skills database
